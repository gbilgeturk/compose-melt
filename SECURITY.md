# Security Policy

## Supported versions

Only the latest released version of compose-melt receives fixes.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Report them privately through GitHub:
[Security → Report a vulnerability](https://github.com/gbilgeturk/compose-melt/security/advisories/new).

You can expect an initial response within a week. Once the issue is confirmed, a fix will be released
and the advisory published with credit to the reporter (unless you prefer to stay anonymous).
